# vercel-best-practices

A project-specific React performance skill. It documents the deliberate
performance practices used in this Trello clone's client and points at the exact
code that demonstrates each one.

- [SKILL.md](SKILL.md) — overview, scope, categories
- [AGENTS.md](AGENTS.md) — how to apply the rules when editing `client/src/`
- [rules/](rules/) — one file per rule (rule → why → where we apply it)

Scoped to our stack (**Vite SPA + Express**); React Server Component / SSR rules
are excluded as not applicable. Curated and written for this repo — not a copy of
any upstream rule set.
